Esse é um projeto criado em Django puro. Uma plataforma aonde pode ser criado chats para conversar com seus amigos.

# Setup

## Clonar projeto
git clone https://github.com/BrenoSantos18/r-chat.git

## Dependências que precisa ter instalado
sudo apt update
sudo apt install python3-full python3-venv

## Crie ambiente env e entre nele
python3 -m venv venv
source venv/bin/activate

## Instale o Django
pip install Django==6.0.1

## Inicie o projeto
python manage.py runserver
